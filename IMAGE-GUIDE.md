# Nora's Upholstery image guide

All active image slots now contain a real photograph or brand asset. There are no
missing image placeholders in the release. To replace a photograph later, prepare
the new image with the same filename and upload it to `public/images/` at the
repository root. GitHub filenames are case-sensitive.

## Preparing website images

- Use WebP for normal website photographs. JPG is also supported.
- Convert HEIC or HEIF photographs before uploading; browsers do not display them reliably.
- Keep the original photograph outside `public/` and upload only the web-ready copy.
- Aim for about 1600 px on the longest side and less than 350 KB when quality permits.
- Do not add text, labels or watermarks to photographs.
- Before and after pairs work best when photographed from the same position and angle.
- Replacing an image with the same filename does not require a code change.
